What was wrong with double-earn

This version of the partner is correct except for one behaviour.

The bug
It ignores reference on an earn, so a repeated earn adds the points again.
Caught by
earn/duplicate-reference — the only case that sends the same earn twice.
Why only one
The other 19 never repeat an earn, so a partner with this bug passes them. A suite is only as good as the mistakes it has a case for.
